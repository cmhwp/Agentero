# Research projects

Use one folder per research project. Keep the project question, decisions, papers, notes, experiments, and next actions together.

Suggested layout:

```text
projects/<project>/
├── README.md          # question, scope, milestones, current decision
├── tasks.md           # next actions and deadlines
├── literature.md      # comparison notes and evidence table
└── experiments/       # data, runs, figures, and result notes
```

Copy `active.md` when starting a project. Project files are ordinary Markdown and can be edited outside Agentero.
